Here's what I want in a viewer:

name: miniSEED viewer

-launchable from the command line as 'pql file1.mseed file2.mseed file3.mseed'
-can read any miniSEED file
-shows up to N traces on a screen (configurable; default N=12)
-in main tab, shows raw traces, each normalized by trace max/min (configurable to allow normalization by global max/min of all traces on the screen). if more than N traces, page through them.
-main tab lets you turn traces on and off, and select time1 and time2 to plot by clicking on the plot
-"magnify" tab shows the selected traces plotted between time1 and time2
-in magnify tab, you can create and save filters, and implement them to all traces or a subset. you can also apply detrending, polarity reversal, etc. to all traces (default) or each individually
-in magnify tab, you can also click a new t1 and t2 on the plot, and zoom in to it
-the third tab is "spectra". it just plots the power spectra of all the traces in the magnify tab. they can be normalized or not (default not), filtered or not (default same as in magnify tab), on log or linear axes (default log-log), and with configurable axis limits. default is 1 spectrum for whole window, but user can select Welch spectrum mode and enter a custom window length.
-in magnify and spectra tabs, you can select overlay off (default; all traces/spectra on different axes) or overlay on (all traces/spectra on the same axes in different colors).
-4th tab is "split". top panel is spectra tab; bottom panel is magnify tab. both can be turned to overlay or not-overlay mode. the spectra recalculate according to zoom-in/zoom-out on magnify tab.
-in all tabs, traces are identified by their network.station.location.channel codes on the left side of the screen. in magnify tab, the RMS amplitude is shown for the current time axis limits and filter.
-configuration options are set in a different screen.

The downloadable file should be very stable where it is expected to work with no updates for many years (just like PQL has not been updated since 2011 and still works).
